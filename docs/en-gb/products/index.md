Alongside client work we build tools of our own. We keep the number small: each
one exists because we needed it ourselves and suspected others did too.

## Free to use, nothing to install

Every tool here runs entirely in your browser. There is no account to create and
no upload step — whatever you paste in stays on your machine.

That is a deliberate choice rather than a limitation. We use these tools on real
configuration files and real API responses, and a tool that phones home is a
tool we would not be able to use.

## Dev Lab

A JSON viewer built for data that is too large and too nested to read by hand.
Paste a response, query it with JSONPath, and the matching fields are
highlighted in place. Matches can be copied out in one click.

It also carries a few smaller utilities we kept reaching for.
